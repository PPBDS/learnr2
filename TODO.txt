5) How do we find all the installed tutorials, e.g. for VS Code extension?

    learnr2::available_tutorials() -- no registration needed, just a folder
    convention. It loops over every installed package, checks each one for
    an inst/tutorials/ folder, and if found, treats every subfolder there as
    one tutorial (reading its title from the .qmd's YAML header). Any
    package that follows the convention is auto-discovered.
    See R/tutorials.R: available_tutorials() + tutorials_in_package().

    Now have a learnr2-native version of both, no Shiny server needed:
    learnr2::student_info() -- ungraded name/email/id form, auto-saves to
    localStorage as the reader types, no submit button, no grading.
    learnr2::download_answers_button() -- gathers every question() and
    student_info() answer already saved on the page into one JSON file and
    downloads it client-side (no server to submit to). See R/submission.R.
    Demoed in inst/tutorials/hello-learnr2/hello-learnr2.qmd section 7.
