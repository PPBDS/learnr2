# learnr2: Interactive Tutorials with Quarto and WebR

Create interactive R tutorials that run entirely in the browser using
Quarto and WebR via the 'quarto-live' extension. Provides learnr-style
authoring conveniences – scaffolding, exercises, hints, solutions, and
quizzes – without Shiny, R Markdown, or a server.
